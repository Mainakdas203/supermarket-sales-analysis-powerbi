# 🛒 Supermarket Sales Analysis – Power BI Dashboard

 Project Overview

This project focuses on analyzing supermarket sales data using **Power BI** to create an interactive and informative dashboard.

The dashboard helps analyze **sales, profit, quantity, delivery performance, products, customers, payment methods, and geographical performance**. Interactive slicers allow users to explore the data based on different regions.

---

 Objectives

The main objectives of this project are to:

- Analyze overall **Sales, Profit, and Quantity**
- Compare **Product Categories and Sub-Categories**
- Analyze sales and profit across **States and Regions**
- Understand **Customer Segment** performance
- Analyze different **Payment Methods**
- Track **Monthly Sales and Profit trends**
- Analyze **Average Delivery** performance
- Provide interactive filtering using **Power BI slicers**

 Dashboard Features

The Power BI dashboard contains:

- *KPI Cards*
  - Total Sales
  - Total Profit
  - Total Quantity
  - Average Delivery

- **Product Analysis**
  - Category-wise sales
  - Sub-category-wise sales

- *Trend Analysis*
  - Monthly Sales
  - Monthly Profit

- *Geographical Analysis*
  - State-level sales and profit
  - Regional analysis

- *Customer Analysis*
  - Customer segment distribution

- *Payment Analysis*
  - Payment-method distribution

- *Interactive Filtering*
  - Region slicer for filtering dashboard visuals
